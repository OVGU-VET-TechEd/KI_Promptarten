# Skill: Quizfragen erstellen

- Erstelle genau 3 Fragen.
- Jede Frage hat 4 Antwortmöglichkeiten (A–D), genau eine ist richtig.
- Markiere die richtige Antwort mit [x], die falschen mit [ ].
- Falsche Antworten sollen typische Fehlvorstellungen von Auszubildenden aufgreifen.
- Schreibe nach jeder Frage eine Zeile "Begründung:" mit einem Satz.
